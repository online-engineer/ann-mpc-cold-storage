# Data folder

This folder holds the 168-hour operating dataset used throughout the paper.
The dataset is **not committed to this repository**; it is generated by
`code/python/generate_dataset.py`.

## How to produce `cold_storage_v2.csv`

From the repository root, run:

```bash
python code/python/generate_dataset.py
```

The script is deterministic (fixed random seed) and writes
`data/cold_storage_v2.csv` with the following columns:

| Column | Unit | Meaning |
|---|---|---|
| Hour | — | Operating hour, 1 to 168 |
| Temperature_C | °C | Cold-room temperature |
| MassFlowRate_kg_s | kg/s | Secondary-loop mass flow |
| SpecificHeatCapacity_kJ_kgC | kJ/kg·°C | Secondary-fluid Cp (ethylene-glycol / water) |
| CoolingLoad_kW | kW | Cooling load via ṁ · Cp · ΔT across the evaporator |
| CompressorPower_kW | kW | Compressor electrical power |
| COP | — | Coefficient of performance (Q_L / W_comp) |

Running the script produces exactly the dataset used to generate the
figures and the results in Table 7 of the paper.

## Why the CSV is not committed

The dataset is a synthetic output of the simulation code in this
repository. Including the derived CSV alongside the generator was
redundant; publishing only the generator keeps the repository the
single source of truth and avoids the two getting out of step.
