Figure file name -> paper figure number mapping
================================================

The file-name numbering reflects the generation order and includes a
gap at position 09 because an earlier Figure 9 was consolidated with
the regression-analysis figure during revision. The next file,
fig10_*, became Figure 9 in the current paper and every subsequent
file name shifted by one relative to the paper number.

Figures 1, 4 and 5 can be regenerated by running the corresponding
Python scripts in code/python/. The MATLAB-produced figures (6-17)
are regenerated by make_figures_v2.m in code/matlab/ after
train_ann_v2.m and run_mpc_v2.m have been executed.
